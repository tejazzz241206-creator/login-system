# Secure Login System Using Python

## Project Description

A simple secure login web application developed using Python and Flask. It allows users to register, log in, and access a protected dashboard. It uses password hashing and session management to improve security.

## Technologies Used

* Python
* Flask
* SQLite
* HTML and CSS

## Features

* User registration
* Secure login authentication
* Password hashing
* Session management
* Protected dashboard
* Logout functionality
* Basic login-attempt protection

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   py -m pip install -r requirements.txt
   ```
4. Run the application:

   ```bash
   py app.py
   ```
5. Open `http://127.0.0.1:5000` in your browser.

## Conclusion

This project demonstrates basic web authentication and security concepts using Python and Flask. It is intended for learning and educational purposes.
